# Fullstack Practical Challenge 💻

Deploy: [Design Project](https://amandaadev.github.io/desafio-pratico-rocketseat/)

## 📌 Descrição

Este repositório foi desenvolvido como parte de um desafio prático do curso para criar uma Landing Page de turismo utilizando apenas HTML e CSS.

A página apresenta informações sobre pontos turísticos de Busan, com imagens, descrições e uma estrutura visual organizada. O principal objetivo do desafio é praticar HTML semântico e estilização com CSS, criando um layout responsivo e visualmente agradável.

## 🧠 Conteúdos praticados

- HTML semântico
- Estruturação de páginas
- CSS básico
- Tipografia com Google Fonts
- Espaçamentos e alinhamento
- Organização de layout

## 🎯 Objetivo

Fortalecer minha base em desenvolvimento frontend, praticando HTML semântico, estruturação de layouts e estilização com CSS.
